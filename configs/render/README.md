# 公共渲染预设

此目录是三轮JSON唯一正式位置：R3为当前默认和已认可的Room8演示风格；R1/R2内容不同，仍用于历史对比和回归，不是重复副本，不自动选用。

art/events/quality区分艺术、传播、质量；任务preset可覆盖质量，不能借机改变冻结的R3。源JSON与任务config_snapshot职责不同，历史快照不随新提交改写。

打包按批准SHA保护三份预设，任务也验证R3批准指纹。后续调参应独立授权和版本化，不编辑旧任务签名强行通过。真实户型、凭证、模型、图片、视频和报告不得放入本目录。

当前效果及六图入口见[R3指南](../../docs/rendering/style.md)，三轮过程在[历史记录](../../docs/archive/20261111_process/render_style_history.md)，逐文件用途见[根清单](../../README.md#完整文件清单)。本轮配置字节不改、不重渲染。
