# 火灾可视化平台 · 燃境 BurnScape

实验室科研原型，Room8为已验证的演示样例。当前四页已只读接入真实登记来源、资产、扫描点位和历史视频；其余能力按实际接入状态显示。没有创建任务、修改R3或更改生产服务。

## 启动与连接

在项目根目录的PowerShell执行：

```powershell
Set-Location frontend
npm.cmd ci
npm.cmd run dev
```

访问 http://127.0.0.1:5173 ，仅绑定本机，端口冲突会报错。Ctrl+C停止。Node26.13.1/npm11.20.0用于本次验证。React/TypeScript/Vite、Tailwind、shadcn Button、R3F/Drei均在前端依赖中。

本机服务配置写入被忽略的 `frontend/.env.local`，不提交：

```dotenv
ROOM_API_TARGET=http://172.25.76.201:8000
ROOM_MINIO_TUNNEL=http://127.0.0.1:19000
```

本轮8000端口可读；9000直连未响应。GLB与检查图通过你在PowerShell建立的隧道读取，保持这个窗口运行：

```powershell
ssh -v -o ConnectTimeout=10 -o ExitOnForwardFailure=yes -N -L 127.0.0.1:19000:127.0.0.1:9000 -p 7777 zhaojy@172.25.76.201
```

密码仅在自己的终端提示中输入，不写进配置、Git或日志。退出后需重建隧道。该转发只监听本机，不修改远端SSH、防火墙或Docker配置。没有配置ROOM_API_TARGET时，页面显示未配置；顶部显示最近一次读取结果，提供手动重新获取，不轮询、不自动提交。

## 四页与资源边界

- 场景资源库：新版sources中的已核验登记来源及当前房间资产；动态取得数据库主键，不使用旧场景下载或渲染接口。
- 房间处理：按实际资产显示登记状态。自动高度、房间边界接口、重新裁切均未接入。
- 火灾工作台：大视口支持旋转、右键平移、滚轮缩放、视角复位、全屏；可切换三张已登记检查图和原V1视频。仅显示当前V1摘要，完整历史在成果中心。
- 参数组折叠为火焰、烟雾、光照、镜头与输出；0–100为无物理单位演示刻度，初值50不是R3默认值；草稿校验、差异、重置保留，不能影响真实渲染。
- 任务与成果：读取真实历史、帧数、文件状态及尝试耗时，视频支持播放、定位和下载；诊断默认折叠。技术完成与人工审核分开表达。
- 禁用项采用灰色样式：下载/导入新场景、裁切、起火点设置、保存预设、提交渲染和授权日志查询。

点位列表和模型可双向选择高亮，查看原始XYZ、GLB坐标与内部/门口类别；不会设置起火点。资源版本面板提供场景/户型/资产版本、GLB SHA、检查图资产ID与V1文件任务号。

顶部显示最近一次成功读取时间。刷新失败保留上次数据并明确标注“非实时”，恢复后按场景/房间/户型/资产版本身份重新定位，不随来源列表顺序改变而切换版本。请求支持超时/取消，不自动重试或创建任务；媒体资源失败可手动重新获取。

三维视口使用按需绘制，并按模块引入Drei；静止时不持续绘制，控制与复位仍可触发重绘。三维分包总大小尚未显著下降。

原点位XYZ仅变换一次为GLB坐标 `(x,z,-y)`，模型本身不再转换。13个内部点和1个门口点由真实review_kind区分；14/14处于模型包围盒内只是一项空间检查，不代替人工墙面边界核验。现有接口没有已核验房间多边形和实际起火点字段，暂不绘制或推断。

## 本机只读代理

2026-11-18：受控测试提交代码已加入，但仍默认只读。`ROOM_TEST_SUBMIT_ENABLED`默认关闭且本机未启用，只有用户单独批准GPU测试后才安排放行；`ROOM_SPATIAL_CONTEXT_ENABLED`也默认关闭，需新接口部署及线上只读验收后启用。不是在此授权部署或渲染。完整按钮/接口/失败交互与当前未验收项见[19日演示清单](../docs/DEMO_20261119.md)。

`local/readonly-proxy.ts`只用于Vite开发/本机preview；静态dist本身不具备代理能力，不能直接当作公网生产交付。

- 默认只接受本机Host/Origin及GET/HEAD；新增唯一受控写入口为精确`POST /api/room-jobs`，由独立开关关闭，严格同源并校验Room8/R3/test八字段白名单。拒绝旧API、正式档及其他写请求，不转发浏览器凭证。
- `/room-assets/<实际资产ID>`仅允许sources关联房间的已上传GLB/检查图，重新取得签名并保留原Host与签名查询。浏览器不接收完整签名URL。
- 通过隧道读取后核对登记长度及SHA256；单资源上限32MiB。未知资源源、重定向、SHA不符或不可达时失败，不回退假数据。
- 视频经现有room-jobs/video接口透传GET/HEAD和单Range，不通过MinIO直链；同源交付避免浏览器跨域配置，未改远端CORS。
- 服务读取日志落在Git忽略的 `data/logs/operations/`，沿用现有schema/trace/request字段，代理向上游传递X-Trace-ID。事件不含路径、请求体、凭证或签名URL。
- 这是JS本机代理的日志适配，不替代现有Python operation_logging。浏览器按钮可信接收、持久化查询与授权界面仍待接入，不能宣称完整按钮→GPU日志链已经验收。

生产化时需另行实现经过认证的只读资产网关，不能公开暴露本机开发代理、数据库或MinIO管理端。

## 验证

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run test
npm.cmd run build
npm.cmd run test:e2e
# 仅在自己已连接服务器和MinIO隧道后，显式执行真实只读验收：
npm.cmd run test:live
```

默认test使用jsdom和替身，含提交白名单/幂等键/重复点击/脱敏关联日志、空间摘要指纹拒绝、版本切换清图、点位、刷新失败保留/恢复身份、超时取消及媒体失败重取。默认e2e启动4173生产预览并通过ROOM_READONLY_DISABLED=1禁用真实服务：原四页检查无业务API请求；新增受控任务测试通过浏览器路由隔离输入检查确认→异步任务号→轮询→刷新恢复→断线停止，绝不调用真实POST。test:live单独访问已运行的5173，不自动建隧道或收集密码；检查真实GLB、点位包围盒、相机操作、三图SHA、V1播放/定位/Range206/下载SHA及控制台/响应式。追加独立V1只读测试，可在隧道不可用时以`npm.cmd run test:live -- --grep 不依赖MinIO隧道`运行。

浏览器测试使用本机Edge无头模式。截图位于忽略目录test-results，不提交私有截图或资源。dist、node_modules、.env.local和日志也不提交。格式整理：`npm.cmd exec prettier -- --write .`。三维依赖按需加载，构建仍有约1MiB三维分包体积提示，后续可继续优化。
