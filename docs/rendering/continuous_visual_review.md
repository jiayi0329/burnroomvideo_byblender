## 现有三帧的五类问题与源码证据

原证据为 `release/out/scenario-keyframe-acceptance/three-stills-02/download/`，仅私有保存。实际渲染器NVIDIA L20，三帧为3.9166667、4、9秒。23份下载证据曾校验通过，不能将其当成V05成果。

| 问题 | 已验证事实 | 判断边界 |
| --- | --- | --- |
| 构图与遮挡 | V04局部相机原始位置(1,-2,0.25)，18mm，观察Z=0.2165；显示墙体截断Z=1.0，正式V1为-0.25 | 中心8条视线通过，不等于整个传播区域无墙体遮挡；图片火焰偏下 |
| 火焰过低、覆盖不足 | `visual_state.geometry`：旧延迟1.5秒，低火持续2.5秒，再增长5秒。4秒实际网格最高约0.187m；9秒支持域6.466㎡ | 算法支持域不等于可见燃烧，不能用面积替代视觉结论 |
| R3复用不完整 | `blender_visual.adapted_material`确实调用R3的`volume_material`，真实材质回执也有四色、密度分层、0.6吸收比例；但V04没有调用`flame_mesh`或`plume_mesh` | 旧版只是材质节点复用，不是V1单火舌/烟柱几何复用 |
| 全场出现一团颜色、黑烟难辨 | 旧版对整个包络使用一个材质：R3的Generated XY径向核心及高度衰减仍以整个对象包围盒计算，噪声却换为世界坐标 | 这是明确的映射结构差异；它对烟层不可见的贡献需A—E真实对照才能确认，不能仅归咎密度 |
| 采样及烟层展示 | 原三帧640×360、32采样、48体积步、tile=4。烟层实际有几何，烟柱/烟层密度控制为3.15/1.08，图片仍不清楚；总览俯视可能遮住下方火焰 | 缺少独立仅烟、仅火及侧视真实对照，不能宣称烟雾已可见 |

| 烟柱/连续烟/烟层系数 | 9×0.35 / 9×0.12 | 独立烟柱9×0.4；连续烟9×0.10；烟层9×0.22，仍需真实可见性确认 |
| 屋顶烟层 | 0.55m，0.65m/s | 0.65m厚度上限，1.25m/s；独立体积，取消单烟柱全局径向遮罩，保留噪声和吸收 |
| 烟雾包络上升 | 1.2m/s | 1.5m/s，受Z=1.85m假设屋顶约束 |
| 展示几何 | 源模型副本按Z=1.0截断 | 仍仅展示副本，按V1的Z=-0.25截断。原BLEND/OBJ/UV/材质不修改 |
| 镜头 | 0—4局部；4—12固定V1总览 | 0—4后退抬高的局部24mm；4—9按房间/烟层包络重构图；9—12更低俯角侧视烟层 |

所有速度是加速假设情景，非物理传播预测。`accelerated_visual.domain_kind`明确为假设Room8视觉支持域；分母是完整可达、可生成封闭底部几何的支持域30.76㎡，不是默认将所有扫描家具认定为燃料。网格不能形成面片的边缘带不计入该分母；不可达单元会单独报告。未实现家具材料分类、局部家具碰撞或CFD。

## 对照与镜头

`visual_review.comparison_config`生成A无火烟、B仅火、C仅烟、D完整烟火、E屋顶剖切五种配置，曝光、机位、主质量不变；E只更改工程屋顶显示。另有“V04火烟+V05同机位同展示裁切同灯光”控制配置。既有三张旧图片的机位/裁切不同，只能称同时间旧成果，不能冒充同机位对照。

三个新机位全部是独立实验相机。总览保留正式V1方向，并拟合完整底部/顶部包络；为避免裁掉屋顶，它不保证正交尺度一定比V1小。后期侧视降低俯角，优先查看下方火场、中部烟羽和上方烟层。CPU投影和候选网格视线检查不代替实际Blender遮挡、穿模及视觉验收。切镜只换相机，`apply(seconds)`仍对同一绝对时间求几何。

## 本轮文件与检验

- `continuous_field.field_from_config`：单源图距离转视觉时间，不改图边与GPU锁。
- `visual_state.geometry`：持续低位支持、边界约束和独立烟层。
- `visual_composition.patch_layout/composition`：不规则疏布R3真实火舌/卷曲烟柱；XY适配活动支持和房间边界。
- `blender_visual.adapted_material/construct`：R3材质、单簇局部坐标、水平烟层遮罩、新镜头和展示副本。
- `scenario_timeline.scenario_report`：3/4/6/9/12秒支持域分母、比例和独立火舌尺寸；不将面积冒充视觉覆盖。
- `visual_review.comparison_config/fit_overview`：一致对照及纯CPU构图。
- `blender_worker.main`：未来真实材质输出连接、实际网格数量、隐藏标志和机位证据。
- 新配置`room8_continuous_a_v05.json`、专项`test_visual_review.py`，均保持渲染关闭或仅离线执行。

专项测试覆盖单源父节点时间序、先烟后火、支持面积、闭合几何、R3实际网格、边界与活动区域约束、确定性、三镜头、A—E隔离、原始材质局部坐标与关联日志。没有对新Blender API或实际效果的通过声明。
